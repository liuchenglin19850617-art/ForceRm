# ForceRm

ForceRm 是一款用于文件/文件夹强制清理与管理的工具。

---

## 使用前准备（重要）

在首次运行 ForceRm 之前，请务必完成以下解压与准备工作：

1. **解压依赖包**：
   * 在项目的根目录下找到 `LibRm.zip` 文件。
   * 将 `LibRm.zip` 直接解压到**项目的根目录**中。
   * 解压完成后，确保解压出的文件与 `ForceRm.pyw` 处于同级目录下。

---

## 启动方法

准备工作完成后，你可以选择以下两种方式之一来启动工具：

* **方式一：标准模式（常用）**
  * 双击运行根目录下的 `ForceRm.pyw` 文件即可启动标准版界面。

* **方式二：高级模式**
  * 双击运行根目录下的 `ForceRm-high.pyw` 文件，启动包含更多高级功能或高权限处理能力的版本。

---

## 运行环境要求

* 操作系统：Windows
* Python 版本：建议 Python 3.x 及以上环境

---

## 常见问题排查

1. **双击后没有反应或提示缺少模块**：
   * 请检查是否已正确将 `LibRm.zip` 解压至根目录。
   * 确保 Python 已正确安装并已添加到系统环境变量 PATH 中。

2. **提示权限不足**：
   * 如果在删除某些系统受保护文件时受阻，请尝试使用“管理员身份”运行或使用 `ForceRm-high.pyw` 版本。
